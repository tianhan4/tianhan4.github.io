演示口径 · Pre-LN / complete forward pass

这里演示同一个标准 Pre-LN block 的完整前向：N₁ = LN₁(X₀)，A = Attention(N₁)，R = X₀ + A，N₂ = LN₂(R)，M = MLP(N₂)，Y = R + M。后续 MLP 使用真实的 N₂，不重新从原始输入开始。两个 GPU 始终处理全部 3 个 token，只分特征 / head；隐藏维 D=8，中间维 F=16，4 个 heads，每头 2 维。

Q/K/V 分别按完整 head 切列，W_O 按对应输入行切分；MLP 的 W_up 切列，W_down 按对应输入行切分。中间激活直接匹配下一层的权重行，不需要 AllGather。两次 AllReduce 分别还原 Attention 输出和 MLP 输出；残差相加与 LayerNorm 都对复制的完整向量本地执行，无需额外通信。顶端分片图是常驻权重布局，主图突出当前运算，不表示训练中反复传输权重。

本例 LayerNorm 的 γ=1、β=0、ε=10⁻⁵；使用 GeLU 小型 MLP、无 mask 的标准 MHA，省略 bias 与 dropout（等价于 dropout 概率 0）。未使用 sequence parallelism、GQA/MQA，也未展示反向传播。权重按 XW 约定画 [输入维, 输出维]，与 PyTorch Linear 常见的转置存储方向相反。通信框表示逻辑集合操作，不代表一个中央 GPU。悬停矩阵元素可查看示例数值。
